## 循环优惠码到底“循环”什么，在哪一步能验出来

循环码的判定标准只有两条：续费时的折扣和下单时一致，以及每一期账单自动抵扣、不需要重新输入。两条都满足才叫循环。只有一条的，是“首期优惠”换了件衣服。

验证只能在实际结算页做，步骤如下。这套流程是 WHMCS 一类计费系统的通用逻辑，不是 LightLayer 独有的规则，任何用这套系统的商家都一样：

1. 选好套餐和计费周期，填完 hostname 和 root 密码，进到结算页。
2. 找到 Promo Code 或“优惠码”输入框，粘贴码。
3. 点旁边的 Validate Code（验证）或 Apply，不要直接点结账。
4. 看两处：订单总额有没有变，明细里有没有多出一行折扣。只改了总额但没显示折扣行的，多半是长周期折扣自动减免，码本身没生效。
5. 确认后才付款。

三个容易白折腾的点：

- **月付基本用不了码。** 相当多商家的优惠码限定年付及以上，月付、季付输进去会提示无效。想用码，先把周期切到年付再看。
- **同一张订单通常只能叠一张码。** 长周期折扣由系统自动减免，不算“叠码”，所以“码 + 年付折扣”是允许的，“码 + 码”一般不允许。
- **码区分大小写。** 复制粘贴比手打稳。

LightLayer 的具体情况和上面这套通用逻辑对得上：活动页写明长周期计费本身有折扣，用优惠码之后还能在长周期折扣上再叠一层。也就是说它把“码”和“周期折扣”当成两层来处理。活动页同时承诺促销产品续费同价不涨价，这一条把循环码最核心的价值（续费不回到原价）单独兜住了。至于某张具体的码是循环还是一次性，必须以结算页显示的折扣行和续费账单为准，公开页面没有逐码标注。
